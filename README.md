# Кәсіби шежіре

«Мен және мені қызықтыратын мамандықтар» облыстық байқауына (4-номинация, «Қадам-life») арналған кәсіби бағдар платформасы.

Қадамдар: шежіре → Холланд тесті → Pick3 → VR-кәсіби сынамалар (электрик, мұнай операторы, медбике, агродрон) → ЖИ «2040 жылдан сұхбат» → кәсіби паспорт.

- Мәтіндер мен деректер: `src/data.js`
- Іске қосу: `npm install`, `npm run dev`
- Жариялау: `main` тармағына push → GitHub Actions автоматты түрде GitHub Pages-ке шығарады.
